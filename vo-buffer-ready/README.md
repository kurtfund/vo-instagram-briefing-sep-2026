# The Visa Orchestrator — Buffer posting pack

Hand this whole folder to a posting agent. Each numbered folder is one Instagram carousel for `@thevisaorchestrator`.

## How to post

Work through the folders in order (`01-` then `02-` then `03-` then `04-`). For each folder:

1. Create an Instagram **carousel** in Buffer.
2. Upload every `01.png`, `02.png`, … file **in filename order**. Do not skip or reorder frames.
3. Paste `caption.txt` into Buffer’s **caption** field.
4. Paste `hashtags.txt` into Buffer’s **hashtag** field. Do not put hashtags in the caption.
5. Do not rewrite the caption, add extra hashtags, or attach extra images.

`post.json` is the machine-readable version of the same instructions.
